# 实验2结果

## 主结果：组件能力阶梯

| 条件 | 成功/总数 | 最终严格通过率 | 相对上一档 | 证据类型 |
|---|---:|---:|---:|---|
| 无Agent（原证明） | 0/21 | 0.0% | — | observed original Gold state |
| 仅单个诊断Agent | 0/21 | 0.0% | +0.0 pp | deterministic no-edit capability condition |
| 双Agent（单轮截断） | 8/21 | 38.1% | +38.1 pp | retrospective trace truncation |
| 双Agent + Controller | 14/21 | 66.7% | +28.6 pp | observed reviewed terminal state |

完整系统相对双 Agent 单轮截断增加 **6/21** 个最终成功，提升 **28.6个百分点**。这6题均来自需要第二轮修复的历史轨迹；该结果说明迭代控制与拒绝后重试在这批轨迹中有贡献，但不等价于随机化因果估计。

## 单 Agent 的独立诊断能力

M3冻结50题诊断集上，单 Evaluator Agent 的证明有效性准确率为 **94.0%（47/50）**，错误类型准确率为 **92.0%**，首错整体定位准确率为 **80.0%**，依赖边 F1 为 **0.9167**。这些是诊断指标，不是修复成功率。

## 项目独特改善点

- 迭代控制挽回：6/14 个最终成功依赖第二轮，占成功案例的 42.9%。
- 保守退出：7/21 个案例被标记为不可局部修复，没有被包装成成功修复。
- 人工确认的问题保持：14/14。
- 人工确认的无新增错误：14/14。
- 人工确认的操作最小性：14/14。
- 局部补丁覆盖：14/14，操作分布为 {'delete': 2, 'insert_before': 4, 'replace': 8}。

## 结论边界

本实验完成的是保存轨迹上的回顾性组件消融。无Agent与仅诊断Agent的0%来自两者都不改写原证明；双Agent单轮结果来自截断完整轨迹；完整系统结果来自实验1已审核终态。除单Agent诊断指标外，本轮没有新provider模型调用，也没有四套系统的独立、等预算随机重跑。因此主表可用于项目内部论证和下一轮实验设计，不应直接写成投稿级因果结论。
