# M3 关于 `m2-028` 的语义勘误

状态：当前解释生效；冻结的 `m3-evaluator-v1.0` 数据、预测、分数和历史验收文件保持不变。

## 错误来源

M3 冻结后的 `HUMAN_AUDIT.md` 和联合验收把 `m2-028` 记为 Gold 缺陷，理由是定理“对所有整数 `n`，`n²≥n`”为真。该判断混淆了定理真值与原证明有效性。

原证明从“`n²≥0`”直接推出“`n²≥n`”，这条推理边无效。按 M2 冻结规则：

- `valid_with_gap / proof_gap` 只用于可在不替换错误推理的情况下补入短标准桥接；
- `m2-028` 必须替换第 2 步，使用 `n(n-1)≥0` 或整数分情况论证；
- 因此 Gold 的 `invalid / algebraic_invalidity / first_invalid_step=2` 自洽；
- M3 的 `valid_with_gap` 预测是预测错误，不是 benchmark 错误。

这一勘误不改变分歧集合、指标数值或冻结摘要，只改变对既有分歧的人工处置解释。历史 v1.0 审计保留以供追溯；后续文档不得再把 `m2-028` 称为 Gold 缺陷。
