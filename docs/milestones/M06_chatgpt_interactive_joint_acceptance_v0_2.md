# M6：ChatGPT 交互式联合验收 v0.2

状态：`chatgpt_interactive_engineering_complete`。

本版本依照用户授权，使用当前 ChatGPT 工作流完成 M6，不调用外部 Provider API，也不要求密码学签名。输入为现有 50 题；M3 的 ChatGPT 诊断与 M5 的 36 项人工处置被确定性投影到九种预注册方法表面，形成 450 个终态、完整账本、评分记录和聚合指标。

九种方法共享同一组历史底层预测，因此这些数据用于验证配置、账本、评分、消融适用性和失败封闭语义，不构成九次独立模型实验。Gold 已暴露，模型调用次数为 0，成本为 0。配对 bootstrap、随机化检验和 Holm 推断不执行，因为共享预测违反独立方法运行的解释前提；不得据此报告方法间显著性或正式科学优势。

Full System 消费 M5 已人工审核的修复处置。在这一交互式工程口径内，已审核修复成功率为 1.0、错误修复率为 0、新错误引入率为 0。Direct Judgment 等不产生补丁的方法，其修复指标保持 `not_applicable`，不以 0 冒充失败。

完成内容包括：九方法不可变配置、50 题稳定样本顺序、450 个终态账本、M3/M5 来源绑定、意向治疗评分、方法适用性、完整聚合、确定性重建、Schema 校验和哈希冻结。由此允许进入 M7 的交互式工程阶段，但不授权正式 M7 Provider 实验或论文量化结论。
