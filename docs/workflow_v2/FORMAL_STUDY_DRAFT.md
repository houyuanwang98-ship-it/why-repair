# 正式实验方案草案与完成门槛

状态：开发方案，尚未冻结或启动正式测试。本文件不把模型复核冒充人工金标准。

## 研究问题与对照

主问题：在相近成功覆盖下，依赖重验是否降低错误成功声明；在相同检查器与编辑下，是否比全图重验节省成本。完整系统端到端比较与受控机制比较分表报告。

端到端保留原证明参照与五种实际修复方法，固定 gpt-5.6-sol/xhigh，独立评分固定 gpt-6-astra/high。工具条件、调用/时间/token 上限一致；各方法可自然提前结束。另报告实际成本曲线，不把统一上限理解为实际计算量相同。

方法定义还须明确披露：当前 Self-refine 与 Generator–critic 都是同一固定模型的三次独立空上下文调用，主要区别是反馈角色的提示措辞。二者不能作为“不同模型的独立批评者”证据；正式比较应把这一点写清，必要时将其定位为反馈提示条件的比较，而不夸大方法差异。

机制主比较优先固定同一初始图、同一局部编辑、同一节点检查器，比较依赖闭包、全图重验、保留过期后代三个策略。后续再单独操纵全文审核与图漏边/错边；不得同时改变多个因素后归因于其中一个。

## 数据来源与冻结

历史 600 题及两个开发先导均不可成为确认性未见测试。需要新来源清单，按源定理家族进行语义去重和分组，隔离开发、人工裁判校准和正式测试。相同定理的改写、错误变体和题解不能跨分组。

来源许可、题目完整性和参考证据核对后，冻结原题、假设、定义域、子目标、原证明及独立人工标签；模型请求只构造白名单字段。正式题目不用于修改提示词、预算、评分规则或选择裁判。

需真实标签区分：命题真/假/未知；原证明正确/缺口/错误/未知；局部修复适用性。不能根据任一实验方法是否成功倒推标签。

## 人工校准和统计

先由实际独立审核者完成匿名校准，记录两份独立判断和分歧裁决；只有一人则如实标为单人审核。模型与人工分别统计误接受、误拒绝和不确定率，保留对应分母与区间。没有人工记录时不输出这些校准误差数值。

主终点为错误成功声明率，同时报告成功声明覆盖率、缺评/未知的上下界。次终点包括在可靠确认的缺陷证明中的修复成功率、正确证明破坏率、反例验证率、每个分配任务及每个成功任务的成本、编辑幅度。

按源定理家族做配对比较和区间估计；同题重复不算独立题。预定比较进行 Holm 校正。人工分层抽审须保留入样概率；总体估计使用相应权重，不能直接把高风险加审比例套到总体。

样本量在第二轮与人工校准后按目标精度确定。若独立样本下仅粗估一个比例，最保守 95% 区间半宽 0.10 对应约 97 个独立单位、半宽 0.05 对应约 385 个单位；这些是规划近似，不能替代配对终点、家族聚类、稀有错误率及人工抽样的正式计算。主比较应进一步根据配对分歧率模拟区间与功效；模型重复次数和总预算一起冻结。

第二轮的[原图预算检查](verification/iteration2_graph_budget.json)显示 18 个已接通图含 2–14 个节点。在不修复、每节点一次模型检查的乐观条件下，构图与全文审核合计需要 4–16 次调用，均未超过 24 次上限。几道 OPC 长题实际先触及 80,000 token 上限。因此正式预算校准须考虑上下文长度、重复审核和修复成本，不能把本轮长题失败简单归因于图节点数必然超过调用上限。
