## S1：建立新契约与独立评分边界

建议新增 `harness/workflow_v2/` 与 `schemas/workflow_v2/`，不原地变更历史契约。

1. 实现 ProblemSnapshot、RunOutcome、FinalJudgment 等契约，按字段白名单构建模型输入。
2. 增加域/假设/量词/子目标冻结和源文本映射。
3. 拆开系统主张、运行终态、模型评分和人工证据；写好聚合器的定义测试。
4. 建立匿名请求构造器，候选与原证明采用相同输入形状，保留私有匿名映射。
5. 实现调用身份、输入摘要、完整恢复与预算账本；后端模型名不可见时保留 null 和未核实状态。
6. 实验模型固定 `gpt-5.6-sol` / `xhigh`，运行外验证固定 `gpt-6-astra` / `high`；校验实际请求，拒绝命令行/环境覆盖及自动替代模型。

验收：Gold、方法名、claimed_outcome 和其他候选不能到达最终裁判；定义域不会遗漏；不确定或反例不能计为成功证明；缺少输出/评分不得丢掉任务分母。

## S3：独立方法运行器与离线语义验收

已新增 `scripts/run_workflow_v2.py`：读取预分配任务，按 method dispatcher 执行真实阶段；不能给同一个生成器传四种方法名要求同时作答。

先实现 original、direct_rewrite 和 full_system，再接 Self-Refine、Generator–Critic、Best-of-n。方法之间不共享模型生成物，独立会话、缓存、预算和终态。机制实验采用另一 input_mode 和输出目录，不混入端到端表格。

以下离线验收使用脚本化响应和确定性小例子；它们验证实现行为，不作为模型效果证据：

| 场景 | 必须观察的行为 |
|---|---|
| 原本正确的证明 | 保留原目标；输出就绪需满足该方法定义，不凭空强制修复 |
| 缺少桥梁引理 | 输出 gap 证书；插入引理后目标与后代重验 |
| 断言为假但原命题仍真 | 允许改写局部；不得升级为全局反例 |
| 原命题为假 | 验证全局反例；计入反例结果，不计证明成功 |
| 诊断或工具不确定 | 一次补证据后仍未知则弃权，不自动生成确定错误 |
| DAG 合法但漏掉最终目标 | 完整性审核发现目标义务，不能直接 proof_ready |
| 修改分支后在汇合点失效 | 汇合节点被重验；无关分支只在完整指纹不变时复用 |
| 删除旧依赖边 | 旧图后代仍进入失效集合，不因边消失而漏检 |
| 节点版本旧、规则库/模型配置变化 | 拒绝旧证书、旧审核或旧缓存，不静默重绑定 |
| 补丁事务中途失败 | 恢复节点、图、队列、版本及摘要；失败调用成本保留 |
| 局部通过但全文不成立 | 内部全篇审核阻止成功主张；外部评分仍独立执行 |
| token 未知、超时、预算耗尽或中断 | 明确非成功终态；可恢复日志，不用零成本或旧文件伪装完成 |
| 外部裁判请求夹带 Gold/方法/旧判词 | 由请求构造器/Schema 拒绝，而非只靠提示词 |
| 请求模型或推理强度与固定配置不一致 | 调用前拒绝；模型不可用时记录失败，不能自动回退到其他模型 |
| 外部结果 unknown、缺失或含多个候选 | 不能计严格接受；保留缺评分母及故障原因 |
| 完整流程被压成单次“角色扮演”输出 | 轨迹验收发现必需调用缺失，拒绝声称真实 full_system |

实施后只运行与变更有关的契约、状态、恢复和隔离测试；无新问题时不反复全量运行历史测试。

## S4：工程先导与裁判校准

工程先导用开发集覆盖上述机制，不先对全部 600 题启动昂贵矩阵。先比较三个已实现方法，再补齐全部基线和机制配置。实际选取案例和来源需在启动前生成清单，不把当前设计文档当作已冻结清单。

验收查看真实调用阶段数、候选完整性、失败分类、预算、工具可见范围与恢复能力。机器配置中的 24 次调用/80,000 token 等只是候选值；根据图规模和先导成本调整，调整记录保留。

在独立人工确认的校准集上评估固定的 `gpt-6-astra` / `high` 评分器，不调整模型或推理强度。所有实验方法固定使用 `gpt-5.6-sol` / `xhigh`。先导之后冻结提示词、工具、预算、抽样与主比较；请求模型 ID 无后端快照证据时明确说明可复现边界。

## S5：完整实验与人工核验

1. 主实验从冻结原始输入独立运行；新测试集与回顾性 600 题分表报告。
2. 机制实验从共享且公开的已核对初始图/诊断运行，仅改变预定因素。
3. 候选冻结后逐份外部评分；独立评分故障在同一评分配置下恢复，不能向生成器回流。
4. 按预先定义的方案安排实际专家抽审与分歧裁决；保留来源与入样概率。
5. 明确全部任务与评分完成度；缺少人工时发布的是模型测量，不能补写 human_verified。

正式样本量、重复次数和预算档在先导后依据功效/精度目标与资源冻结，当前不伪造确定数值。
