## 为什么现在扩大 smoke 不能成为完整消融

现有输入引用历史 M3 图和 M5 错误证书；一次模型输出不包含真实的“生成补丁—独立评估—应用—后代失效—重验—下一轮”。因此，单轮与多轮、启用与关闭后代失效这些配置位尚不能在这条 smoke 路径产生可测量的执行差异。

下一版必须连接已有控制器并实现这些行为，才能用 false repair 或修复成功率衡量机制。增加题量、修改提示词或让模型自报成功无法替代这一工作。

## 下一版验收要求

1. 首先区分端到端比较和固定诊断输入下的修复比较；共享历史错误证书的结果只能回答后者。
2. 五个方法使用同一批冻结题目、同一模型和明确总预算；每个 assignment 独立会话。
3. 补丁必须经过控制器实际执行；自评结果不计为 verified repair。
4. 独立评估调用只接收当前证明与公开任务条件；不得读取测试 Gold。
5. 每十个 assignment 保存原始日志、失败和检查点；不覆盖失败重跑。
6. 先完成三题端到端验收，再扩大至五方法乘五十题；全部结果仍按 AI 辅助单人复核边界报告。

本轮不将已有 27 个输出重复标为新增实验。该文件是缺口记录，不代表上述新运行器已经实现。
