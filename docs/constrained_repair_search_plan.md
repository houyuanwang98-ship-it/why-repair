## 1. 论文定位与本轮决定

保持已确定的论文标题与摘要主线：
**Why–Repair: Mathematically Constrained Search for Local Proof Repair**。
不把“不可靠验证器下的风险保证”改成当前论文的第二条主线；它是后续研究方向。
当前聚焦：双侧契约约束候选，作用域明确的反馈引导编辑区域调整，
预计修改影响与剩余成本决定继续局部修复、扩大区域还是重写。

核心研究假设（待验证）：当大部分论证有效且影响范围有限时，复用原证明思路和
仍有效的内容可减少总 token 与重建成本；当接口变化导致广泛影响时，重写可能更合算。
不预设局部修复总是更便宜、更正确，也不承诺找到全局最小补丁。

“双侧契约”与“局部修复加重写”各自不能直接声称首次提出。
候选贡献是：以证明边界义务及反馈的作用域为依据，联合搜索补丁内容和编辑区域，
并解释何时保留原论证、何时放弃原路线。新颖性与优势仍需文献核对和实验支持。

## 2. 任务定义与双侧契约

固定原定理 T、原假设 Γ、定义域和变量作用域；证明表示为版本化依赖图 G。
选择编辑区域 R（可以是非连续的依赖子图），候选补丁为 P_R。

- U_R：区域可使用的外部上游前提，绑定节点版本、来源和审核状态。
- D_R：保留的区域外推理所需的跨界输出，绑定每项义务的消费节点及理由。
- 补丁义务：Γ, U_R ⊢_{P_R} D_R。
- 下游需求是待证明目标，不是补丁可以引用的已知前提。
- 不能把原题目标当成已成立事实，也不能通过增加原题假设完成修复。
- 未决上游前提不能静默视为成立；依赖抽取和契约提取也可能错误，需要审核。

契约不是把所有后文结论塞入目标列表，而是提取所有保留分支实际需要的边界输出。
变量绑定、定义、量词、存在性见证及作用域也是接口的一部分。
契约遗漏会漏验，提取过强会误判不可修复；两者都须作为独立失败原因记录。

## 3. 联合搜索的示例（说明性案例，非实验结果）

原题：x ≥ 0，证明 x² ≥ 0。原证明：

1. x ≥ 0，因此 x > 0。
2. 定义 q = x²/x，于是 q = x ≥ 0。
3. x² = xq，因此 x² ≥ 0。

只编辑第 1 步时，保留第 2 步的除法至少要求 x ≠ 0。
义务 x ≥ 0 ⇒ x ≠ 0 被 x = 0 反驳。把第 1 步改成正确的 x ≥ 0 仍不足以连接后文。
在没有遗漏合法前提、且该除法必须对全部允许输入执行的条件下，当前边界不可行。

将第 2 步纳入区域后，重新计算边界：保留第 3 步要求 q ≥ 0 与 x² = xq。
新补丁为“令 q = x，则 q ≥ 0 且 xq = x²”，不再需要除法。
原定理不变，旧要求不是被随意删除，而是被新边界要求替代。
x = 0 仍是合法输入，但不再反驳新契约；旧反例不能无条件用于剪枝新区域。

## 4. 反馈的作用域与搜索动作

| 反馈类型 | 合法用途 | 禁止推论 |
|---|---|---|
| candidate_refuted：核验反例只反驳当前候选 | 拒绝候选，记录适用条件，搜索其他候选 | 当前区域的所有候选均不可行 |
| contract_refuted：反例满足完整上游条件并违反必要边界义务 | 先复核契约提取，再指导区域调整 | 原始定理必为假 |
| review_undetermined：核验不能决定 | 请求补充证据、弃权或预算内继续 | 当作通过或确定反例 |
| search_exhausted：预算内没有找到 | 启发式扩大或转入重写，明确触发原因 | 已证明当前区域不可修复 |
| extraction_invalid：依赖或契约提取错误 | 修正表示并撤销相应反馈 | 扩大区域掩盖表示错误 |

只有经核验的反例可以产生相应作用域内的硬约束。剪掉候选族必须有共享必要条件的依据；
不能从一个失败候选概括到所有相似候选。自然语言审核意见默认是搜索指导，
不能冒充精确验证证书。保留失败、拒绝、超时、未决和重复候选记录。

区域扩展必须指明纳入哪些节点、消解哪个边界障碍、产生哪些新跨界义务。
包括所有保留分支，防止通过删除困难节点丢弃目标义务。
初期优先实现沿依赖消费者的下游扩展；若向上游扩展，需要重新定位和确认授权边界，
不能绕过当前 v2 的未决前缀阻断规则。预算耗尽只能安全退出，不能自动宣布成功。

## 5. 影响分析与局部／扩大／重写决策

后代数量是粗略特征，不是重写阈值。明确区分：

1. proof_only：内部证明改变，结论、假设和作用域接口不变。
2. interface_changed：输出结论、条件、变量定义或适用范围改变。
3. route_changed：后续原路线不能沿用，需要扩大编辑或重写。

分别记录声明后代集合、保守失效集合、预计需改写集合和实际核验集合。
“后代多”不等于“都需要改写”；接口相同也不自动证明旧证据可安全复用。
首版沿用现有保守失效与整篇重扫策略，不提前上线语义缓存优化。

候选动作：continue_local、expand_region、rewrite_proof、await_evidence、stop_budget。
选择依据包括接口变化、受影响文本量／义务难度、失败次数、可复用内容、剩余预算，
以及各动作的预计剩余成本与成功机会。初版为透明、可配置的启发式，
不能把主观分数当作校准成功概率，不预设“后代超过 30% 就重写”。

比较前必须满足固定原题、合法证据与完成审核约束；成本不能交换正确性要求。
已经发生的成本计入报告，但下一动作依据剩余预期收益决定，避免沉没成本驱动。
重写在任务定义上是 R 覆盖全部证明的极端情况，实现上显式记录模式切换。
可以参考原思路，但旧证明和审核标签不是重写结果的正确性证据；全篇须重新审核。
保留上一版本作为可恢复候选，新补丁／重写审核失败不得破坏原始记录。

总成本口径：诊断与契约 + 全部补丁尝试 + 影响核验 + 最终审核。
包括输入、输出和 Provider 报告的推理 token（如可用）、缓存计费、失败重试、费用与延迟。
重写采用同样口径，报告累计成本和每次决策的剩余成本估计；不能只比最后输出字数。
缺失计量项标为 unavailable，而不是零。

## 6. 建议的可审计记录（待设计 Schema，不是现有 API）

- RepairContract：proof/graph/theorem/assumptions digest、region nodes/versions、
  upstream sources/statuses、downstream obligations/consumer nodes、scope、review state。
- SearchCandidate：parent state、contract digest、patch digest、edit footprint、review outcome。
- ScopedConstraint：candidate/contract/family 作用域、精确前提、反例、核验方法及结果、版本。
- ImpactAssessment：接口变化类型、各影响集合、遗漏依赖的不确定性、成本估计依据。
- SearchDecision：可选动作、选中动作、数学或启发式触发原因、预算、估计与实际成本。

图、区域或契约变化后必须检查所有约束的适用性，不匹配的证据失效。
候选通过不等于会话完成；必须通过现有独立分支重扫和最终原题目标覆盖审核。
“按协议通过”不是形式化可靠性保证，也不因重复审核或双 Agent 而自动获得独立性。

## 9. 摘要、理论与证据的边界

保留摘要主线，不把拟实现机制写成已验证优势。
用户给出的摘要中，50 题 94% 是历史 auditor 分类结果，不是首错率或本方法修复率；
其 artifact、分母与审核来源须在写作前核对，本次不重新认证该数字。
Lyapunov 案例需定位代码与轨迹，并说明是在修复已有证明还是仅合成证书；
历史 pilot 成功与未决个案分别报告，不能替代新方法的对照实证。

可研究条件性替换命题：在边界依赖完整、合法上游成立、补丁交付全部接口、
保留下游推理有效的前提下，替换保持目标可推导性。
这不是自然语言审核器能正确判断这些前提的保证；不宣称一般情形的搜索完备性或风险上界。
