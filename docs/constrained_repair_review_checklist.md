## 2. 数学示例：请审核是否可用作论文方法图

原题：x ≥ 0，证明 x² ≥ 0。
原证明：① x > 0；② 令 q = x²/x，则 q = x ≥ 0；③ x² = xq，因此 x² ≥ 0。

- R={①} 时，保留②至少需要 x ≠ 0。x=0 满足原假设却违反该要求。
- 这反驳当前接口，不反驳原题；不能偷偷增加 x>0 作为原假设。
- R={①,②} 时，③需要 q≥0 与 x²=xq；改为“令 q=x”可以交付这两个条件。
- q 的定义/作用域必须一并跨界传递，不能只交付一条失去变量绑定的等式。
- 如果论文要求采用真实历史证明而非说明性构造例，请指定案例与已有专家标签位置。

此处是推导供审阅，不是声称有人已经独立审核。当前代码只对精确表达式片段重放反例，
没有自动完成这个自然语言多节点修复；不把它写成运行结果。
