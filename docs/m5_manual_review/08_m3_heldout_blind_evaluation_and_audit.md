# M3 人工证据 4：held-out 盲测与 50 题结果人工审计

> [!IMPORTANT]
> 历史 M3 运行明确 `blind_to_gold=false`，只能作为工程回归。机器不能把已暴露 Gold 重新变成 held-out，也不能独立判断自然语言模型输出的数学正确性。

## 机器无法验证

- 模型、Prompt 调试者和 reviewer 是否事先接触 Gold；
- 新测试集是否真正 held-out 且未进入训练/开发；
- 模型输出中的数学解释、首错和依赖是否正确；
- 人工审计者身份、独立性和是否受 Gold 锚定；
- 失败运行、异常和弃权是否全部保留；
- 模型提供方和版本声明是否与真实调用一致。

## 人工执行顺序

1. 数据保管人冻结新的 held-out 题集并隐藏 Gold。
2. 冻结模型、Prompt、参数、代码和指标后运行。
3. 在揭示 Gold 前锁定全部原始输出和失败运行。
4. 两名人工审核者先检查输出数学质量，再揭示 Gold 评分。
5. 分别报告切分、节点分类、依赖边、首错、节点裁决、错误接受和弃权。

## 新 held-out 题的要求

新题不得是以上 50 题的表面改写；需覆盖相同错误层级并预先冻结类别比例。每道题登记来源、Gold 保管人、创建摘要、候选锁定时间和 Gold 揭示时间。

## 完成判据

存在新的、时间顺序可验证的 held-out 盲测；全部输出和失败运行在揭示 Gold 前锁定；人工数学审计完整；指标可从原始记录回放。否则 M3 结果不得作为论文正式模型性能。
