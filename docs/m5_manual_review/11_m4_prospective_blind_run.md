# M4 人工证据 7：前瞻性盲态反例发现运行

> [!IMPORTANT]
> 现有 M2/M3 题目和 Gold 已暴露，机器无法把历史运行重新变成盲测。必须由独立保管人创建新的未暴露挑战，并保证先锁定候选、后揭示 Gold。

## 机器无法验证

- 新题是否真的未被模型、开发者和 reviewer 看过；
- 保管人是否独立并始终控制 Gold；
- 候选输出是否在 Gold 揭示前锁定；
- 失败候选是否完整保留；
- 新挑战是否代表目标分布而非刻意挑选容易题。

## 人工设计要求

新建一批不来自现有 50 题及其轻微改写的代数挑战，覆盖正确证明、局部假命题、全局假定理、定理误用、计算错误、不支持表达式和无反例/undetermined。题目总数、类别比例和主要指标必须在运行前冻结。

## 每道新题必须人工登记

题目 ID、来源/原创者、创建时间、原题、假设、证明全文、目标结构、Gold、Gold 保管人、题目与现有语料相似性检查、挑战摘要、候选锁定时间、Gold 揭示时间、评分和争议裁决。由于这些题尚未创建，目前不存在可诚实列出的题目文本；不得用现有 50 题冒充新盲题。

## 时间顺序

1. 保管人创建题目和 Gold，分别哈希并隐藏 Gold。
2. 只向生成/发现系统发布挑战文本。
3. 锁定全部候选、失败输出和运行清单并签名。
4. Gold 保管人记录揭示时间后开放 Gold。
5. 独立 scorer 计算发现率和有效率；争议交第三方。

## 完成判据

所有新题都有可验证的“创建与 Gold 锁定 → 候选锁定 → Gold 揭示 → 评分”时间链，失败运行完整，保管人与 scorer 身份明确。此前 publication blind discovery rate 必须保持 null。
