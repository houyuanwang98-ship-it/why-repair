# Person A 人工验证包：按里程碑与案例分工

> [!IMPORTANT]
> 本文件只包含 Person A 的数学职责。Person A 不验证 API 账单、模型调用真实性或 Controller 事务实现，也不得生成待审补丁。完整题目文本见本目录 `02_person_a_full_patch_review.md`。

## M0：A–J 的数学验证

- **A**：核验消去律及 `a≠0`，判断是否需独立中间命题。
- **B**：核验 `a=0,x=1,y=2` 满足前提并否定结论。
- **C**：用“是否新增可独立判真的命题”区分 accepted 与 gap。
- **D**：确认 `n^2=2k^2` 为首个错误、`k=1` 为反例、原定理可修。
- **E**：区分群与阿贝尔群，判断缺假设或 false local claim。
- **F**：判定 `x^2=-1` 在实数域错误，但不把下游代数变换自动判错。
- **G**：判断定义是否良定义并明确域和值域。
- **H**：核验极值定理的闭区间连续性条件。
- **I**：确认句法残片不是可判真的数学节点。
- **J**：外部引理陈述和条件缺失时保持 undetermined。

## M1：数学契约签署

Person A 逐项批准 ProofInstance、ProofNode、DependencyEdge、LocalObligation、EvaluationRecord、ErrorCertificate、CounterexampleCertificate、AmbiguityAnalysis 和 PatchReview 的数学含义；确认 `accepted` 不由格式、模型置信度或 Controller 自动产生。

## M5：每题补丁审核

对上述 50 题中真实 Pilot 产生的每个补丁，Person A 单独检查数学有效性、原失败、问题保持、新错误、原子编辑最小性和最终后代路径；未产生补丁的题不伪造 review，false repair 必须保留。
