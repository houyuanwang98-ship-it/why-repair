# M4 人工证据 5：11 个反例的双外部复核与签名

> [!IMPORTANT]
> 两名外部 reviewer 必须互不查看对方结论、不得使用模型辅助，并在比较前分别锁定和签署。SHA-256 只能证明内容未变，不能证明签署者身份。

## 机器无法验证

- reviewer 的真人身份、独立性和数学资格；
- reviewer 是否在锁定前看过另一人的答案；
- 自然语言前提与目标是否被忠实理解；
- 人工签名对应的私钥持有人和组织授权；
- 审核过程是否真的无模型辅助。

## 11 题逐题人工审核

每题两位 reviewer 都要检查：所有原假设为真、目标确为假、赋值属于声明结构、反例范围是原定理而非仅某一步。

- **m2-021**：`a+b` 偶是否推出 `a,b` 都偶；核验 `a=1,b=1`。
- **m2-022**：两个非零实数之和是否非零；核验 `x=1,y=-1`。
- **m2-023**：`4|n^2` 是否推出 `4|n`；核验 `n=2`。
- **m2-024**：所有素数是否奇；核验 `p=2` 及其素性。
- **m2-025**：`x^2=y^2` 是否推出 `x=y`；核验 `x=1,y=-1`。
- **m2-026**：`ab` 偶是否推出两者都偶；核验 `a=2,b=3`。
- **m2-027**：正实数 `a<b` 是否推出 `1/a<1/b`；核验 `a=1,b=2` 和不等号方向。
- **m2-029**：`x+y=0` 是否推出二者都零；核验 `x=1,y=-1`。
- **m2-042**：实数 `x<y` 是否推出 `x^2<y^2`；核验 `x=-2,y=-1`。
- **m2-043**：整数 `a|bc` 是否推出 `a|b` 或 `a|c`；核验 `a=6,b=2,c=3`，并注意欧几里得引理缺少素数条件。
- **m2-048**：`ab=0` 是否推出 `a=0` 且 `b=0`；核验 `a=0,b=1`，区分“或”与“且”。

## 签署细则

使用 `external_human_signoff_packet_v1.json` 的两个独立 slot；分别填写 reviewer、组织、审核样本、锁定时间、决定、公钥指纹和 detached signature。两份签名都应绑定同一全局反例归档 SHA-256。

## 完成判据

11 题被两名不同外部 reviewer 全量复核，先独立锁定后比较，两个签名均可验证，分歧有第三方裁决。缺任一项时严格 M4 真人证据门保持失败。
