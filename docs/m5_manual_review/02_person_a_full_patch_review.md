# M5 人工审核 2：Person A 全量补丁数学复核

> [!IMPORTANT]
> **本文件中的数学结论必须由独立 Person A 真人逐例审核。** 自动测试只能检查格式、摘要和状态一致性，不能代替数学真值、隐藏假设、最小性或 reviewer 独立性判断。下方 50 题均须人工处理；未全部签署时本项必须保持 `pending`。

## 目的与责任人

本项要求独立 Person A 对真实 Pilot 中所有声称成功的补丁以及所有 false repair 进行数学审核。审核者不得是生成补丁的 Repair Generator，也不得把 Generator 的隐藏推理当作证据。

自动复核、同一 Agent 自我复核或项目维护者代填姓名不能替代独立人工判断。

## 机器无法独立验证的事项（必须人工确认）

- 自然语言证明的每一步在数学语义上是否成立；
- 是否存在未写出的隐藏假设、量词变化或定义域缩小；
- 补丁是否真正解决原失败，而不是通过改题或弱化结论绕过；
- 新增文字是否引入细微歧义、新错误或错误定理适用；
- 删除某个原子编辑后，证明在数学意义上是否仍完整；
- reviewer 是否真正独立、没有查看 Gold 或 Generator 隐藏推理；
- reviewer 身份、审核时间和签名是否真实。

程序只能验证字段、摘要、版本、身份字符串和检查项之间的一致性，不能把这些结构检查替代为数学真值或真人独立性证明。

## 审核者可见材料

- 冻结题面、定理、定义域和全局假设；
- 目标节点及其精确版本；
- 版本化直接前提；
- ErrorCertificate 和原失败推理边；
- PatchProposal 及其规范摘要；
- 明确列出的允许证据；
- M4 v1.1 已接受且只读的反例证书；
- 声明版本的定理库条目和可重放精确计算。

审核者不得查看 Gold 修复、Generator 隐藏思维过程、缓存中的其他答案或其他审核者尚未锁定的结论。

## 每个补丁的数学审核细则

### 新增或替换节点

- [ ] 每个节点能从精确版本前提推出；
- [ ] 定理使用满足全部前提、范围和定义域；
- [ ] 计算可重放，没有除零、符号、量词或边界错误；
- [ ] 没有使用允许证据之外的事实；
- [ ] 节点文字与自包含命题表达同一数学含义。

### 原失败是否解决

- [ ] 明确指出原失败推理边；
- [ ] 补丁实际修复该边，而非绕开、删除关键目标或改写问题；
- [ ] 若原证书含反例，补丁不再受到同一反例攻击；
- [ ] 仅改善措辞但未补足逻辑时必须拒绝。

### 问题保持

- [ ] 定理没有削弱或更换；
- [ ] 没有新增未声明假设；
- [ ] 定义域没有缩小；
- [ ] 目标和量词范围没有漂移；
- [ ] 无关证明分支没有被改写；
- [ ] 改变题目的建议被标记为 `changes_problem`，不计入修复成功。

### 新错误与后代

- [ ] 补丁没有引入新的假命题、歧义或不受支持推理；
- [ ] 所有依赖旧版本的后代已经 stale；
- [ ] 重建后代使用新的依赖版本；
- [ ] 新目标和全部受影响后代均有独立重验记录；
- [ ] 最终目标路径不存在 `rejected`、`undetermined` 或未决节点。

### 操作最小性

审核者必须逐个删除原子编辑：

- [ ] 每个编辑都有唯一 `edit_id`；
- [ ] 删除任一编辑会使原错误复现或证明路径不完整；
- [ ] 存在可删除而不影响修复的编辑时，标记 `not_minimal`；
- [ ] 字符更短不等于数学上更小，不以文风偏好拒绝补丁。

## False repair 专项记录

所有模型声称成功但被人工拒绝的补丁都应保留，并至少归入：数学错误、原失败未解决、隐藏假设、目标改变、定义域改变、无关分支变化、新错误、非最小、证据不足或陈旧绑定。不得只统计被接受补丁。

## 分歧处理

Person A 与 Person B 对执行事实有分歧时，由 Controller 日志判定版本、缓存和状态；对数学有效性有分歧时，交给未接触双方结论的第三名数学审核者。未解决分歧保持 `undetermined`，不得多数投票强行接受。

## 完成判据

真实 Pilot 中每个成功补丁和 false repair 均有完整、非 Generator 身份的人工复核；所有接受补丁通过数学有效性、问题保持、无新错误、最小性和后代重验门；审核记录锁定并绑定摘要。完成后才能把 `person_a_full_pilot_review` 从 `pending` 改为 `passed`。

## 附录：50 个 Pilot 例子的完整人工审核文本

以下文本来自冻结的 `data/benchmarks/m2/gold/algebra_pilot_v1.jsonl`。本附录只提供原题、假设和待审核证明，不提供 Gold 结论、错误标签、反例或最小修复，避免向审核者泄漏答案。

### m2-001：证明两个偶整数之和为偶数
- 假设：x、y 为偶整数。
- 证明：n1. 存在整数 m,n，使 x=2m，y=2n。 n2. 于是 x+y=2m+2n=2(m+n)。 n3. 因为 m+n 是整数，所以 x+y 是偶数。

### m2-002：证明若实数 x>2，则 x^2>4
- 假设：x 为实数且 x>2。
- 证明：n1. 由 x>2 得 x-2>0，并且 x+2>0。 n2. 两个正数的乘积为正，所以 (x-2)(x+2)>0，即 x^2-4>0。 n3. 因此 x^2>4。

### m2-003：证明对任意整数 n，n^2+n+1 是奇数
- 假设：n 为整数。
- 证明：n1. 相邻整数 n 与 n+1 中至少有一个是偶数，所以 n(n+1) 是偶数。 n2. 因此存在整数 k，使 n(n+1)=2k。 n3. 于是 n^2+n+1=n(n+1)+1=2k+1，所以 n^2+n+1 是奇数。

### m2-004：证明若整数 n^2 为偶数，则 n 为偶数
- 假设：n 为整数且 n^2 为偶数。
- 证明：n1. 假设 n 是奇数。 n2. 那么存在整数 k 使 n=2k+1，从而 n^2=4k^2+4k+1 是奇数。 n3. 这与 n^2 为偶数矛盾，所以 n 为偶数。

### m2-005：证明若实数 a<b，则 a+c<b+c
- 假设：a,b,c 为实数且 a<b。
- 证明：n1. 在不等式 a<b 两边同时加 c。 n2. 得到 a+c<b+c。

### m2-006：证明若整数 a 整除 b 且 a 整除 c，则 a 整除 b+c
- 假设：a,b,c 为整数，a|b 且 a|c。
- 证明：n1. 存在整数 m,n 使 b=am 且 c=an。 n2. 于是 b+c=a(m+n)。 n3. 所以 a|b+c。

### m2-007：证明对任意实数 x，(x+1)^2≥0
- 假设：x 为实数。
- 证明：n1. 实数的平方非负。 n2. 所以 (x+1)^2≥0。

### m2-008：证明若实数 x,y 均为正数，则 xy 为正数
- 假设：x,y 为实数且 x>0、y>0。
- 证明：n1. 正数相乘仍为正数。 n2. 因此 xy>0。

### m2-009：证明奇整数与偶整数之积为偶数
- 假设：x 为奇整数，y 为偶整数。
- 证明：n1. 存在整数 m,n，使 x=2m+1，y=2n。 n2. 于是 xy=(2m+1)2n=2((2m+1)n)。 n3. 所以 xy 是偶数。

### m2-010：证明若实数 x=y，则 x+z=y+z
- 假设：x,y,z 为实数且 x=y。
- 证明：n1. 等式两边同时加 z。 n2. 得到 x+z=y+z。

### m2-011：证明两个奇整数之和为偶数
- 假设：x、y 为奇整数。
- 证明：n1. 存在整数 m,n，使 x=2m+1，y=2n+1。 n2. 所以 x+y 是偶数。

### m2-012：证明若整数 a|b 且 b|c，则 a|c
- 假设：a,b,c 为整数，a|b 且 b|c。
- 证明：n1. 存在整数 m,n 使 b=am 且 c=bn。 n2. 因此 a|c。

### m2-013：证明若实数 x≠0，则 x^2>0
- 假设：x 为实数且 x≠0。
- 证明：n1. 实数平方非负。 n2. 所以 x^2>0。

### m2-014：证明若整数 n 为偶数，则 n^2 为 4 的倍数
- 假设：n 为偶整数。
- 证明：n1. 存在整数 k 使 n=2k。 n2. 因此 n^2 是 4 的倍数。

### m2-015：证明若 a,b 为正实数，则 a/b 为正数
- 假设：a,b 为实数且 a>0、b>0。
- 证明：n1. 正数的倒数为正数。 n2. 因此 a/b>0。

### m2-016：证明若整数 n 能被 6 整除，则 n 能被 3 整除
- 假设：n 为整数且 6|n。
- 证明：n1. 存在整数 k 使 n=6k。 n2. 所以 3|n。

### m2-017：证明任意三个连续整数之和能被 3 整除
- 假设：n 为整数，三个整数为 n,n+1,n+2。
- 证明：n1. 它们的和为 3n+3。 n2. 所以该和能被 3 整除。

### m2-018：证明若 x,y 为实数且 x=y，则 x^2=y^2
- 假设：x,y 为实数且 x=y。
- 证明：n1. 等式两边分别乘以 x 和 y。 n2. 因此 x^2=y^2。

### m2-019：证明若整数 a,b 都是 5 的倍数，则 a-b 是 5 的倍数
- 假设：a,b 为整数且 5|a、5|b。
- 证明：n1. 写 a=5m，b=5n。 n2. 所以 a-b 是 5 的倍数。

### m2-020：证明若实数 0<x<1，则 x^2<x
- 假设：x 为实数且 0<x<1。
- 证明：n1. 不等式 x<1 两边乘以 x。 n2. 得到 x^2<x。

### m2-021：证明若 a+b 为偶数，则 a、b 都为偶数
- 假设：a,b 为整数且 a+b 为偶数。
- 证明：n1. 偶数可以写成 2k。 n2. 因此 a=2m 且 b=2n。 n3. 所以 a、b 都为偶数。

### m2-022：证明任意两个非零实数的和非零
- 假设：x,y 为非零实数。
- 证明：n1. 非零数相加仍非零。 n2. 所以 x+y≠0。

### m2-023：证明若整数 n^2 能被 4 整除，则 n 能被 4 整除
- 假设：n 为整数且 4|n^2。
- 证明：n1. 因为 4|n^2，所以 2|n。 n2. 因此 4|n。

### m2-024：证明所有素数都是奇数
- 假设：p 为素数。
- 证明：n1. 素数只有 1 和自身两个正因数。 n2. 所以 p 不能被 2 整除。 n3. 因此 p 是奇数。

### m2-025：证明若实数 x^2=y^2，则 x=y
- 假设：x,y 为实数且 x^2=y^2。
- 证明：n1. 两边开平方。 n2. 得到 x=y。

### m2-026：证明若整数 ab 为偶数，则 a 与 b 都为偶数
- 假设：a,b 为整数且 ab 为偶数。
- 证明：n1. 偶数乘积只能由两个偶因子产生。 n2. 因此 a、b 都是偶数。

### m2-027：证明若正实数 a<b，则 1/a<1/b
- 假设：a,b 为正实数且 a<b。
- 证明：n1. 取倒数保持不等号方向。 n2. 所以 1/a<1/b。

### m2-028：证明任意整数 n 都满足 n^2≥n
- 假设：n 为整数。
- 证明：n1. 因为 n^2 是非负数。 n2. 所以 n^2≥n。

### m2-029：证明若实数 x+y=0，则 x=y=0
- 假设：x,y 为实数且 x+y=0。
- 证明：n1. 和为零时每个加数都必须为零。 n2. 因此 x=0 且 y=0。

### m2-030：证明无理数与有理数之和是无理数
- 假设：x 为无理实数，r 为有理数。
- 证明：n1. 无理数不属于有理数集，而有理数属于有理数集。 n2. 一个不属于有理数集的数与一个属于有理数集的数相加，结果仍不属于有理数集。 n3. 因此 x+r 是无理数。

### m2-031：证明若整数 n 为偶数，则 n+1 为奇数
- 假设：n 为偶整数。
- 证明：n1. 存在整数 k，使 n=2k。 n2. 于是 n+1=2k+2。 n3. 所以 n+1 可以写成 2k+1 的形式，是奇数。

### m2-032：证明若实数 x>1，则 x^2>x
- 假设：x 为实数且 x>1。
- 证明：n1. 由 x>1 可知 x^2>1。 n2. 因此 x^2>x。

### m2-033：证明方程 x^2=1 的实数解恰为 x=1 或 x=-1
- 假设：x 为实数且 x^2=1。
- 证明：n1. 由 x^2-1=0 得 (x-1)(x+1)=0。 n2. 等式两边约去因子 x-1，得到 x+1=0。 n3. 因此 x=1 或 x=-1。

### m2-034：证明对任意实数 a，都有 sqrt(a^2)=|a|
- 假设：a 为实数。
- 证明：n1. 平方与开平方互相抵消，所以 sqrt(a^2)=a。 n2. 又因为每个实数 a 都等于 |a|，所以 sqrt(a^2)=|a|。

### m2-035：证明若实数 a<b 且 c<0，则 ac>bc
- 假设：a,b,c 为实数，a<b 且 c<0。
- 证明：n1. 将不等式 a<b 两边同时乘以 c，得到 ac<bc。 n2. 因为 c 是负数，所以把不等号改为相反方向，得到 ac>bc。 n3. 因此 ac>bc。

### m2-036：证明对任意正整数 n，n^2+n 是偶数
- 假设：n 为正整数。
- 证明：n1. 当 n=1 时，n^2+n=2 是偶数。 n2. 当 n=2 时，n^2+n=6 是偶数。 n3. 因此对任意正整数 n，n^2+n 都是偶数。

### m2-037：证明两个偶整数之和为偶数
- 假设：x,y 为偶整数。
- 证明：n1. 因为两个偶整数之和为偶数，所以 x+y 为偶数。 n2. 因此命题成立。

### m2-038：证明对任意实数 x，都有 |x|≥x
- 假设：x 为实数。
- 证明：n1. 实数的平方总是非负，所以 x^2≥0。 n2. 因此 |x|≥x。

### m2-039：证明若整数 a|b 且 b|c，则 a|c
- 假设：a,b,c 为整数，a|b 且 b|c。
- 证明：n1. 由 a|b 可反向得到 b|a，由 b|c 可反向得到 c|b。 n2. 根据整除的传递性，由 c|b 和 b|a 得 c|a。 n3. 因此 a|c。

### m2-040：证明两个偶整数之和为偶数
- 假设：x,y 为偶整数。
- 证明：n1. 存在整数 m,n，使 x=2m 且 y=2n。 n2. 于是 x+y=2mn。 n3. 因为 2mn 是偶数，所以 x+y 是偶数。

### m2-041：证明若实数 a=b，则对任意实数 c 都有 a/c=b/c
- 假设：a,b,c 为实数且 a=b。
- 证明：n1. 等式两边同时除以 c。 n2. 得到 a/c=b/c。

### m2-042：证明若实数 x<y，则 x^2<y^2
- 假设：x,y 为实数且 x<y。
- 证明：n1. 平方函数严格递增。 n2. 因此 x^2<y^2。

### m2-043：证明若整数 a|bc，则 a|b 或 a|c
- 假设：a,b,c 为整数且 a|bc。
- 证明：n1. 由欧几里得引理，a|b 或 a|c。 n2. 结论成立。

### m2-044：证明若实数 a=b，则 (a+c)^2=(b+c)^2
- 假设：a,b,c 为实数且 a=b。
- 证明：n1. 展开两边，得到 (a+c)^2=a^2+2ac+c^2，且 (b+c)^2=b^2+bc+c^2。 n2. 因为 a=b，所以 a^2+2ac+c^2=b^2+bc+c^2。 n3. 因此 (a+c)^2=(b+c)^2。

### m2-045：证明若整数 a|b，则 a^2|b^2
- 假设：a,b 为整数且 a|b。
- 证明：n1. 存在整数 k 使 b=ak。 n2. 平方得 b^2=a^2k。 n3. 所以 a^2|b^2。

### m2-046：证明对任意实数 a,b，都有 |a+b|≤|a|+|b|
- 假设：a,b 为实数。
- 证明：n1. 因为 |a+b|=sqrt(a^2+b^2)。 n2. 又因为 sqrt(a^2+b^2)≤sqrt(a^2)+sqrt(b^2)=|a|+|b|。 n3. 所以 |a+b|≤|a|+|b|。

### m2-047：证明若整数 n 为奇数，则 n^2 为奇数
- 假设：n 为奇整数。
- 证明：n1. 写 n=2k+1。 n2. 则 n^2=4k^2+2k+1。 n3. 所以 n^2 为奇数。

### m2-048：证明若实数 ab=0，则 a=0 且 b=0
- 假设：a,b 为实数且 ab=0。
- 证明：n1. 由零乘积性质可知 a=0 或 b=0。 n2. 所以 a=0 且 b=0。

### m2-049：证明两个有理数之和为有理数
- 假设：x,y 为有理数。
- 证明：n1. 存在整数 p,q,r,s，且 q,s≠0，使 x=p/q，y=r/s。 n2. 于是 x+y=(p+r)/(qs)。 n3. 因为 p+r 与 qs 都是整数且 qs≠0，所以 x+y 是有理数。

### m2-050：用数学归纳法证明前 n 个正奇数之和等于 n^2
- 假设：n 为正整数。
- 证明：n1. 当 n=1 时，等式 1=1^2 成立。 n2. 假设前 n 个正奇数之和等于 n^2。 n3. 加入下一个奇数 2n+1 后，总和为 n^2+2n+1=n+1。 n4. 所以前 n+1 个正奇数之和等于 (n+1)^2，归纳完成。
