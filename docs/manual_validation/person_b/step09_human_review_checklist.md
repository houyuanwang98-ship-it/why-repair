仅人工检查发布材料中机器难以判断的可理解性、表述边界、披露充分性、案例呈现和发布后处置可操作性。`step09_release_reproduction.md` 中的 5 个发布对象保留为定位目录。项目所有者已确认全部对象完成审核，六项结果均与机器／分节点 Agent 结果一致；逐对象同步结果见 `../../../data/manual_validation/person_b_step09_object_results.jsonl`。

## 不纳入本清单

- 审核者签名、身份、时间、分支、提交 SHA 或其他签署信息。
- 安装、测试、命令执行、文件存在性、哈希、版本一致性、字段完整性和指标复算。
- 对题干、证明、答案、数学案例、论文数字或机器输出作正确性比对。
- 主张与数据逐项对表、证据链完整性等可由结构化规则或脚本核验的内容。
- 来源权利、许可证以及“合理、合法、合规”等判断。
- 凭据、密钥和固定敏感模式的自动扫描结果。
