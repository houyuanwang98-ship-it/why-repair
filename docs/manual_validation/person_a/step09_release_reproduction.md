# 第9步：独立复现、论文主张与发布审核——Person A工作包

## 简介

在干净环境复现项目，并逐发布物检查数字、主张、数学案例、权利、隐私、物料一致性与勘误流程。

本工作包分配给 **Person A**，共 **5 个发布对象**。只完成本文件不足以关闭该步骤；必须与另一人的工作包合并、比较分歧并完成必要裁决。

## 本步要求

1. 只使用发布材料，不依赖开发机缓存或隐藏知识。
2. 每项主张建立主张—数据—运行—统计—案例证据链。
3. 自然语言审计不得表述为形式化证明保证。
4. 逐文件检查权利、隐私和敏感信息。
5. 演练发布后严重错误处置流程。

## 执行纪律

1. 逐项独立判断，不复制系统预测或另一审核者答案。
2. 机器结果只作定位线索，不构成数学、语义、权利或发布正确性证据。
3. 不确定时填写“不确定”或“需修订”，不得猜测通过。
4. 保留原始意见；复核与裁决不得覆盖初次记录。
5. 每个抽样、异常或需要裁决的对象都必须填写结论、理由和证据路径；其余对象由批次决定覆盖。
