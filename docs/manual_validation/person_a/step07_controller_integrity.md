# 第7步：Controller、缓存、状态与真实运行完整性审核——Person A工作包

## 简介

通过人工代码审查和主动对抗测试验证权限、版本、回滚、缓存、账本、Provider 记录和压力情形。

本工作包分配给 **Person A**，共 **68 项对抗检查**。只完成本文件不足以关闭该步骤；必须与另一人的工作包合并、比较分歧并完成必要裁决。

## 本步要求

1. 每项攻击必须记录期望行为、实际行为和复现步骤。
2. 独立核对真实 Provider 控制台与账单。
3. 高严重度 finding 修复后必须重放原攻击。
4. 任何选择性漏记或失败开放均判为不通过。

## 执行纪律

1. 逐项独立判断，不复制系统预测或另一审核者答案。
2. 机器结果只作定位线索，不构成数学、语义、权利或发布正确性证据。
3. 不确定时填写“不确定”或“需修订”，不得猜测通过。
4. 保留原始意见；复核与裁决不得覆盖初次记录。
5. 每个抽样、异常或需要裁决的对象都必须填写结论、理由和证据路径；其余对象由批次决定覆盖。
