# Person A Step 9 精简人工审核清单

## 本步简介

通读 5 个发布对象，判断面向使用者的材料是否清楚、克制且可执行。安装、哈希、指标复算等由机器完成。原材料见 `step09_release_reproduction.md`。

## 仅需人工审核

- [ ] **材料自足**：关键使用步骤无需开发者口头补充。
- [ ] **主张边界**：未把自然语言审计或经验结果夸大为形式化证明或普遍保证。
- [ ] **限制披露**：失败、弃权、成本、已知限制和人工依赖说明清楚。
- [ ] **案例呈现**：没有以标题、排序或篇幅明显美化结果或隐藏失败。
- [ ] **勘误可执行**：更正、受影响版本标记和下游通知有明确入口。
- [ ] **语境敏感信息**：未发现固定模式扫描难以识别但明显不宜公开的内容。
