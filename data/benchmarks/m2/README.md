# M2 pilot benchmark

`pilot_50.jsonl` contains the shared, immutable source items. It contains no annotator answers.

`person_a_annotation_template.jsonl` is a blank working template. Person A's completed annotations belong in `private/person_a_annotations.jsonl`, which is intentionally ignored by Git until both annotators have independently locked their work.

Person B should create and manage a separate Person B path on their own branch. This branch does not define or fill Person B artifacts.
