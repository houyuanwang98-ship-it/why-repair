# M3 Pilot5 v1 交互式 Codex 试跑

## 定位

本次运行使用当前 Codex 会话作为 skill 的 active host agent，不调用外部 API。它用于验证图构建、逐轮裁决、恢复执行和指标生成，不作为论文正式模型成绩。当前会话接触过 M2 Gold，因此本次运行不是盲测。

## 修复内容

首次运行发现两项实现缺陷：中文节点类型识别不足；含数学操作的首节点会被自动当作已成立。修复后：

- 增加中文定义、假设、引入、计算和结论表达的分类规则；
- “因为 P，所以 Q”按推导结论处理，而不是因含公式就判为计算步骤；
- 首节点包含开方、约去、平方、同乘同除等操作时，必须进入计算裁决；
- 中文“整数、实数、域、环、群、向量空间”等能够建立相应计算上下文。

## 逐题结论

- `m2-001`：正确识别为 `valid`；
- `m2-011`：正确识别第 2 步为可修复缺口；
- `m2-018`：按多解释策略保持 `undetermined`；
- `m2-025`：正确识别原定理为假，并将错误开平方定位在第 1 步；
- `m2-033`：正确识别第 2 步非法约去零因子。

## 仍需处理

1. 10 个节点中仍有 1 个类型错误，需要在更大样本中判断是否属于系统性规则缺失；
2. 图构建多报 1 条依赖边，后续应强调只输出直接依赖；
3. 本次仅有 5 题且非盲测，满分证明级指标不能作为能力结论；
4. 正式论文实验仍需固定、可复现的本地模型或 API 模型，并使用未参与调试的盲测集。
